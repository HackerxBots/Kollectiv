Welcome to Kollektiv

Describe what you want to build. Kollektiv plans it into dependency-ordered tasks, then runs them across as many free worker accounts as you have — in parallel, with shared state.

  • ✦Plan, then parallel work. One brief becomes a wave of tasks an agent pool picks up.
  • ◈Nothing lost between sessions. Every run leaves a handoff: what is done, what is next, what blocks it.
  • ◍Your tools. Gmail, Calendar, Drive, Notion, GitHub and any REST API become callable from the dashboard or MCP.

Point it at your API

This page is static and talks to exactly one origin — yours. Paste the API base URL (the default is http://localhost:8000, or the same host when this is served from /ui).

No telemetry, no analytics: the only requests this page makes are to that address.

Keyboard first

Everything is reachable without the mouse, and a few shortcuts are worth learning on day one.

  • ⌘⌘K / Ctrl K command palette — jump to a view or run a project.
  • gg then p, c or a — go to a section.
  • tt theme, r refresh, esc close.
