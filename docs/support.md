# Support the project

> Part of the [Kollektiv documentation](README.md) · back to the [README](../README.md)

Kollektiv is free software under the MIT licence. It is built and maintained by
its contributors, and there are two ways to help it financially. That is the
whole list.

## 1. Sponsor on GitHub

Use the **Sponsor** button at the top of the repository, or go to
`https://github.com/sponsors/HackerxBots`. GitHub's sponsorship is a monthly or
one-off payment to the maintainer, with no platform fee on the project's side.

## 2. Donate

Donations are welcome through the same Sponsor page. If you want a different
route (for example a fiscal host), it will be linked here once one is set up.

## What support is for

Time for reviews and releases, the CI and CodeQL minutes, and the hosting of the
documentation and dashboard preview. Nothing else.

## What support does not change

- **No feature is paid for.** The self-hosted product is complete, and it stays
  complete.
- **No ads, sponsor lines or placements** inside the software, the dashboard,
  generated code, prompts or answers.
- **No data collection.** Kollectiv has no telemetry and no analytics, and a
  donation does not add any.

## Other ways to help

- Star the repository and tell someone who would use it.
- Report a bug with `kollektiv check --json` attached (secrets are redacted).
- Send a pull request. The contributing guide is in
  [CONTRIBUTING.md](../CONTRIBUTING.md).
- Write a worker shim for a provider or agent we do not support yet
  (see [agent runtimes](agent-runtimes.md)).
